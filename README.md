# assignment2-kimberlyjung
This repo is for individual assignment 2

The penguin.csv dataset was used for this analysis, which includes information about penguins, including species, sex, body mass, and other physical characteristics

The name of my data analysis script is penguin-analysis.R. It loads the penguins.csv dataset, produces summary statistics, creates a frequency table comparing penguin species and island, and calculates the mean body mass for each penguin species

To reproduce the analysis, place penguins.csv and penguins_analysis.R in the same folder. Open penguins_analysis.R in RStudio and run the script
